# ARCH — контракты плагина «Почта»

1. Ящик — источник истины. Плагин — курьер: read-only по Mailbox/,
   состояние доставки — своя память (кэш), дедупликация по «что видел
   с запуска».
2. Доставка — только в явно назначенную `targetSession`; чужие сессии
   не трогаем. Пробуждение (`followup`) возможно лишь как явный конфиг
   `wake: true` (доводка), по умолчанию — нет.
3. Пороговый контракт: при `limitPerHour = N` более N доставок за час
   не происходит; пропущенные письма остаются в ящике, каждый пропуск
   оставляет причину в `lastSkip`.
4. Инструменты регулирования — общие для UI и агента через один метод
   хоста (practices/user-actions); действие «отключить меня» имеет силу
   немедленно в текущем процессе.
5. Новые типы событий в журнал сессии не добавляем (запрет харнесса);
   статусы — только инструменты/конфиг.
