# dsh-mailbox — «Почта»

**Статус:** 0.1.0 — заготовка, по умолчанию выключена.
**Боль:** протокол `Mailbox/` — файлы; доставка сейчас ручная
(перечитывание ящика). Письма теряются между сессиями Координатора и
Помощника.

## Что делает

Следит за ящиком `config.root/<role>/`; новое письмо → короткая заметка в
сессию `targetSession` (через inbox-инъекцию, без пробуждения агента).

## Право получателя (контракт хозяина 2026-11-05)

Завалить письмами получателя — значит потерять его. Поэтому:

- `mailbox_throttle(action: pause|resume|limit, limit?)` — пауза,
  возобновление, почасовой порог (0 = без лимита);
- `mailbox_status` — текущий режим, доставлено за час, причина
  последнего пропуска;
- конфиг строки (`enabled`, `limitPerHour`) — постоянный рубильник;
  переживает рестарт, тул-пауза — до рестарта (доводка: configEditor).

Просроченный лимит НЕ теряет письмо: файл остаётся в ящике, получатель
разбирает сам. Плагин письма не правит и не удаляет.

## Установка / разработка

`install_bundle` с путём репо; после правок `make check`; чек-лист доводки
— `INTERNAL.md`.
